## User Scenarios & Testing _(mandatory)_

### User Story 1 - 상단 네비게이션 바 스크롤 겹침 수정 (Priority: P1)

사용자가 게임 화면(Dashboard)에서 스크롤을 내릴 때, 상단 바("Blue Banker" 로고 및 방 ID)가 콘텐츠 위에 정상적으로 고정되지 않고 콘텐츠와 겹쳐서 표시되는 문제가 수정된다.

**Why this priority**: 상단 바가 겹치면 사용자가 현재 방 정보를 확인하기 어렵고, 앱의 전문성과 완성도가 떨어져 보임. 가장 눈에 띄는 시각적 버그.

**Independent Test**: 게임 화면에서 위아래로 스크롤할 때 상단 바가 항상 콘텐츠 위에 표시되는지 확인

**Acceptance Scenarios**:

1. **Given** 게임 화면(Dashboard)에 접속한 상태, **When** 페이지를 아래로 스크롤, **Then** 상단 네비게이션 바가 화면 최상단에 고정되고 다른 콘텐츠 위에 표시됨
2. **Given** 게임 화면에서 스크롤이 아래로 내려간 상태, **When** 빠르게 위로 스크롤, **Then** 상단 바가 깜빡임 없이 안정적으로 표시됨

---

### User Story 2 - 금액 입력 시 화면 튀는 현상 수정 (Priority: P1)

사용자가 토지 매입, 송금 등 금액을 입력할 때 첫 숫자 입력 단계에서 화면이 갑자기 이동하거나 튀는 현상이 수정된다.

**Why this priority**: 입력 중 화면이 튀면 사용자가 입력 내용을 놓치거나 오입력할 수 있어 거래 오류로 이어질 수 있음. 핵심 기능의 사용성에 직접적인 영향.

**Independent Test**: 금액 입력 필드에 숫자를 입력할 때 화면 위치가 유지되는지 확인

**Acceptance Scenarios**:

1. **Given** 거래 모달이 열린 상태, **When** 금액 입력 필드에 첫 번째 숫자를 입력, **Then** 화면이 스크롤되거나 점프하지 않음
2. **Given** 키보드가 열려있는 상태에서 금액 입력 중, **When** 연속으로 숫자를 입력, **Then** 입력 필드와 주변 UI가 안정적으로 유지됨
3. **Given** 모바일 기기에서 거래 모달 사용 중, **When** 가상 키보드가 나타나는 순간, **Then** 입력 필드가 화면에서 사라지지 않고 보이는 상태 유지

---

### User Story 3 - 송금 화면 숫자와 '원' 글자 겹침 수정 (Priority: P2)

송금 화면에서 금액을 입력할 때 입력된 숫자와 '원' 글자가 겹쳐 표시되어 가독성이 떨어지는 문제가 수정된다.

**Why this priority**: 시각적 문제이지만 금액 확인이 어려워 오 입력 가능성 있음. 사용자 경험에 영향을 주지만 기능 자체는 동작함.

**Independent Test**: 다양한 자릿수의 금액을 입력했을 때 숫자와 '원' 글자가 겹치지 않는지 확인

**Acceptance Scenarios**:

1. **Given** 송금 모달이 열린 상태, **When** 1억 원 이상의 큰 금액(예: 100,000,000)을 입력, **Then** 숫자와 '원' 글자 사이에 충분한 간격이 있어 명확히 구분됨
2. **Given** 금액 입력 중, **When** 숫자를 추가하거나 삭제, **Then** '원' 글자 위치가 입력된 숫자와 겹치지 않도록 자동 조정됨

---

### Edge Cases

- 최대 자릿수(10자리) 도달 시 추가 입력 차단 및 사용자 피드백
- 작은 화면(320px 너비) 모바일 기기에서의 UI 배치
- 가상 키보드 높이가 다른 다양한 모바일 기기에서의 동작
- 빠른 연속 입력 시 화면 안정성

## Requirements _(mandatory)_

### Functional Requirements

- **FR-001**: 상단 네비게이션 바는 스크롤 시 항상 다른 콘텐츠 위에 표시되어야 함 (z-index: 1000, 모달보다 낮음)
- **FR-002**: 금액 입력 필드에 포커스가 이동하거나 값이 변경될 때 화면 레이아웃이 갑작스럽게 변하지 않아야 함
- **FR-003**: 금액 입력 필드에서 입력된 숫자와 '원' 통화 표시 텍스트 사이에 최소 8px 여백이 있어야 함
- **FR-004**: 모든 UI 요소는 최소 320px 너비부터 다양한 화면 크기(모바일/태블릿)에서 정상적으로 표시되어야 함
- **FR-005**: 가상 키보드가 나타날 때 입력 필드가 화면에서 가려지지 않아야 함

### Key Entities

- **상단 네비게이션 바**: 앱 로고와 방 ID를 표시하는 화면 최상단 고정 영역
- **금액 입력 필드**: 거래 금액을 입력받는 텍스트 입력 컴포넌트. 통화 단위 표시 포함
- **거래 모달 (TransactionModal)**: 송금, 토지 매입 등 다양한 거래 유형을 처리하는 팝업 UI

## Success Criteria _(mandatory)_

### Measurable Outcomes

- **SC-001**: 스크롤 시 상단 바와 콘텐츠가 겹치는 현상이 0% 발생
- **SC-002**: 금액 입력 시작 시 화면 점프/튀는 현상이 0회 발생
- **SC-003**: 최대 자릿수(10자리) 금액 입력 시에도 숫자와 '원' 글자가 겹치지 않음
