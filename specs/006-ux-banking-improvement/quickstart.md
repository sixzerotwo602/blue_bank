# Quickstart: UX 뱅킹 개선

**Feature**: 006-ux-banking-improvement
**Date**: 2026-01-26

## 개발 환경 설정

```bash
# 1. 저장소 클론 (이미 완료된 경우 스킵)
git clone <repo-url>
cd blue_banker

# 2. 기능 브랜치 체크아웃
git checkout 006-ux-banking-improvement

# 3. 의존성 설치
npm install

# 4. 개발 서버 실행 (별도 터미널에서)
# 백엔드
cd backend && npm run dev

# 프론트엔드 (다른 터미널)
cd frontend && npm run dev
```

## 테스트 실행

```bash
# 전체 테스트
npm test

# 프론트엔드 테스트만
cd frontend && npm test

# 백엔드 테스트만
cd backend && npm test
```

## 검증 체크리스트

### US1: 송금 대상 명확화 (P1)

- [ ] 대시보드에서 "송금하기" 버튼 클릭
- [ ] 금액 입력 후 하단에 2개 버튼 확인:
  - [ ] "플레이어에게 송금" (파란색)
  - [ ] "은행으로 송금" (빨간색)
- [ ] "플레이어에게 송금" 클릭 시 받는 사람 선택 필요
- [ ] "은행으로 송금" 클릭 시 바로 PAY_COST 처리

### US2: 실시간 뱅킹 자산 정보 (P1)

- [ ] 실시간 랭킹 목록에서 자산 정보 확인
- [ ] 토지 있는 플레이어: `🏞️ 토지: N개 (X만원)` 형식
- [ ] 건물 있는 플레이어: `🏢 건물: N개 (X만원)` 형식
- [ ] 자산 없는 플레이어: `🏞️ 0 | 🏢 0` 형식

### US3: 건물 유형 구분 (P2)

- [ ] "토지/건물 매입" 버튼 클릭
- [ ] 4버튼 그리드 확인: 토지 / 호텔 / 빌딩 / 별장
- [ ] 각 건물 유형 매입 후 랭킹에서 아이콘 구분 확인:
  - [ ] 호텔: 🏨
  - [ ] 빌딩: 🏢
  - [ ] 별장: 🏡

### US4: 용어 명확화 (P1)

- [ ] 대시보드 버튼: "토지/건물 매입" (비용지불 제거됨)
- [ ] 모달 타이틀: PAY_COST 시 "은행에 납부"
- [ ] "비용 지불" 텍스트 앱 전체에서 사라짐

### 모바일 반응형 (320px)

- [ ] 개발자 도구에서 320px 너비 설정
- [ ] 4버튼 그리드 2열 배치 확인
- [ ] 2개 확인 버튼 세로 배치 확인 (필요시)
- [ ] 모든 텍스트 잘리지 않음 확인

## 성공 기준

| ID | 기준 | 검증 방법 |
|----|------|-----------|
| SC-001 | 송금 모달에서 "플레이어에게 송금"/"은행으로 송금" 버튼 색상 구분 | 시각적 확인 |
| SC-002 | 실시간 랭킹에서 토지/건물 개수+평가액 표시 | 게임 플레이 후 확인 |
| SC-003 | "비용 지불" → "은행에 납부" 용어 통일 | 전체 UI 검색 |
| SC-004 | 건물 유형(호텔/빌딩/별장) 아이콘 구분 | 매입 후 랭킹 확인 |
