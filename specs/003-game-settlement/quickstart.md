# 퀵스타트: 게임 정산 (Game Settlement)

## 전제 조건

- 게임이 `PLAYING` (진행 중) 상태여야 합니다.
- 게임 종료는 반드시 **호스트(HOST)**만 트리거할 수 있습니다.

## 테스트 방법

1. **게임 시작**:
   - 브라우저 탭을 2개 이상 엽니다.
   - 호스트: 방 생성 -> 게임 시작.
   - 다른 유저: 방 참가.

2. **라운드 진행**:
   - 자산 차이를 만들기 위해 서로 송금하거나 자산(토지/건물)을 구매합니다.

3. **게임 종료**:
   - 호스트: 대시보드 맨 아래로 스크롤합니다.
   - 호스트: 빨간색 "게임 종료" 버튼을 클릭합니다.
   - 호스트: 모달에서 "확인"을 클릭합니다.

4. **정산 확인**:
   - 모든 화면에 "정산 결과"가 뜨는지 확인합니다.
   - 순위가 맞는지 확인합니다 (총 자산 = 현금 + 자산 가치).
   - 상세 내역이 올바른지 확인합니다.
   - "홈으로 돌아가기"를 눌러 나갑니다.
