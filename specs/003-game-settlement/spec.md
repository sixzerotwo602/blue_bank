# 명세서: 게임 정산 (Game Settlement)

## 목표

게임 호스트가 공식적으로 게임을 종료하고, 모든 플레이어의 자산 가치를 합산하여 순위를 매긴 후 상세한 정산 결과를 보여주는 기능을 제공합니다.

## 사용자 시나리오

### 1. 호스트의 게임 종료

- **행위자 (Actor)**: 게임 호스트
- **사전 조건**: 게임이 진행 중 (`PLAYING` 상태).
- **행동**: 호스트가 대시보드 하단으로 스크롤하여 빨간색 "게임 종료" 버튼을 클릭합니다.
- **시스템**: 되돌릴 수 없다는 경고와 함께 확인 모달을 표시합니다.
- **행동**: 호스트가 확인을 누릅니다.
- **시스템**:
  - 게임 상태를 `ENDED`로 변경합니다.
  - 최종 순위를 계산합니다.
  - 모든 플레이어에게 게임 종료 이벤트를 전송합니다.

### 2. 정산 결과 확인

- **행위자 (Actor)**: 모든 플레이어
- **사전 조건**: 호스트가 게임을 종료했습니다.
- **행동**: 없음 (자동).
- **시스템**:
  - 즉시 "정산 결과" 모달/오버레이를 화면에 띄웁니다.
  - 총 자산(내림차순) 기준으로 정렬된 플레이어 목록을 보여줍니다.
  - 각 플레이어의 상세 자산 내역을 표시합니다.

## 기능 요구사항

### 1. 게임 종료 트리거

- **UI**: "게임 종료" 라벨이 붙은 버튼.
  - **색상**: 빨간색 (`bg-red-600`).
  - **위치**: 대시보드 페이지의 맨 하단.
  - **가시성**: 오직 **호스트**에게만 보임.
- **상호작용**:
  - 클릭 시 "정말 게임을 종료하시겠습니까?" 확인 모달 팝업.
  - 확인 시 백엔드로 `game:end` 이벤트 전송.

### 2. 정산 로직 (Backend)

- **신호**: `game:end` 이벤트 처리.
- **계산**:
  - **총 자산** = `현금(Cash)` + `부동산 가치(Asset Value)`.
  - 총 자산 내림차순으로 플레이어 정렬.
- **상태 업데이트**: 방(Room) 상태를 `ENDED`로 변경.
- **브로드캐스트**: 최종 순위 데이터가 포함된 `game:ended` 이벤트 전송.

### 3. 정산 화면 (Frontend)

- **트리거**: `game:ended` 이벤트 수신 시 활성화.
- **UI 컴포넌트**: 전체 화면 오버레이 또는 대형 모달.
- **내용**:
  - **제목**: "게임 종료" / "최종 정산".
  - **순위 목록**:
    - 등수 (1위, 2위...).
    - 닉네임.
    - **총 자산**: 강조 표시 (예: 금색/굵게).
    - **상세 내역**:
      - 보유 현금.
      - 부동산 자산 가치.
      - (선택 사항) 보유 토지/건물 개수.
- **네비게이션**: 하단에 "홈으로 돌아가기" (Go Home) 버튼. 클릭 시 메인 화면으로 이동.

## 성공 기준

- 호스트는 "게임 종료" 버튼을 통해 게임을 정상적으로 종료할 수 있어야 합니다.
- "게임 종료" 클릭 시 확인 팝업이 떠야 합니다.
- 종료 확정 시, 접속 중인 모든 클라이언트 화면이 정산 화면으로 자동 전환되어야 합니다.
- 플레이어들은 (현금 + 자산 가치) 총합으로 올바르게 순위가 매겨져야 합니다.
- 각 플레이어의 현금과 부동산 자산이 구분되어 상세히 표시되어야 합니다.

## 가정

- "상세 정보"는 현금과 부동산 가치의 구분을 의미합니다.
- 오직 호스트만이 게임을 종료할 권한을 가집니다.
